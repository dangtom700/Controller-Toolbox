Detailed Description

Header-only template sliding mode controller for embedded targets.

BasicSMC<Scalar> implements first-order discrete SMC with boundary-layer saturation - the same algorithm as DiscreteSMC - without virtual dispatch, Eigen, or std::function overhead. Suitable for float usage on MCUs.

Algorithm:

s[k] = c_e * e[k] + c_de * (e[k] - e[k-1]) // sliding surface
sat = clamp(s[k] / phi, -1, 1) // boundary-layer saturation
u[k] = clamp(+K * sat, uMin, uMax) // output (+K: compute(r-y) convention)

Convention: compute(error) where error = r - y (error = r[k] - y[k]).

Typical embedded usage (float):

ctrl::BasicSMCParams<float> p;
p.c_e = 1.0f; p.c_de = 0.05f; p.K = 3.0f; p.phi = 0.2f;
p.uMin = -1.0f; p.uMax = 1.0f;
ctrl::BasicSMC<float> smc(p);
float u = smc.compute(setpoint - measurement);

7// SimActuator - IActuator adapter backed by a SimPlant.
8//
9// write(u) applies the control input to the plant:
10// - Non-finite values (NaN, +/-Inf) are rejected; the last valid output is
11// repeated and the plant is stepped with that value. This matches the
12// "hold-last" actuator fail-safe behaviour expected from real hardware.
13// - An optional saturation limit [uMin, uMax] (defaults to +/-inf) is applied
14// before forwarding to the plant, mirroring physical actuator limits.
15//
16// lastOutput() returns the most recent value actually applied to the plant.
17namespace ctrl {
18

38 }

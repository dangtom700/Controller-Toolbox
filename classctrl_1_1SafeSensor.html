double ctrl::SafeSensor::read ( )
inlineoverridevirtual

Return the inner sensor's reading, or the last valid value when invalid.

Also rejects non-finite inner values (NaN, ±Inf) even when isValid() == true. Increments the stale counter on any rejected sample.

Returns
Most recent valid (finite) measurement. Never NaN or Inf.

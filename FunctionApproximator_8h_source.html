8// FunctionApproximator - data-driven Taylor (polynomial) and Pade (rational)
9// approximation from a dataset of (x, y) sample pairs.
10//
11// Both backends fit the approximant by solving a linear least-squares problem
12// against the supplied data - no symbolic function required. This matches
13// the toolbox's identification-from-data philosophy (same as RLS and N4SID).
14//
15// -----------------------------------------------------------------------------
16// Taylor (polynomial) backend
17// -----------------------------------------------------------------------------
18// Fits: f(x) approx = P(x) = a0 + a1x + a2x^2 + ... + a_nx^n
19//
20// Method: Vandermonde matrix V (rows = data points, cols = powers 0..n),
21// QR least-squares solve -> coefficient vector a.
22//
23// Best for: smooth functions away from poles, evaluation at any x, cheap.
24// Watch out: high-degree polynomials can overfit and oscillate (Runge's
25// phenomenon). Keep n <= 8 unless you have many data points and
26// the function is well-behaved.
27//
28// -----------------------------------------------------------------------------
29// Pade (rational) backend
30// -----------------------------------------------------------------------------
31// Fits: f(x) approx = P(x)/Q(x), deg(P)=m, deg(Q)=n, Q(x)=1+q1x+...+q_nx^n
32// (Q is normalised so that Q(0)=1, avoiding the trivial all-zero solution.)
33//
34// Method: Rewrite as a linear system in (p0...p_m, q1...q_n) by moving the
35// denominator to the right-hand side:
36// P(x_i) - f(x_i).Q(x_i) = 0 for each data point i
37// Collect into a matrix equation and solve in least-squares sense.
38// This is the standard Sanathanan-Koerner / linearised approach.
39//
40// Best for: functions with poles or asymptotes, step-response transients,
41// fractional dead-time filters.
42// Watch out: denominator roots can land inside your evaluation domain,
43// causing division-by-zero. Use hasPoleInDomain() to check.
44//
45// -----------------------------------------------------------------------------
46// Fractional dead-time helper
47// -----------------------------------------------------------------------------
48// padeDelayFilter(theta_frac, Ts) builds a discrete-time first-order Pade
49// approximant for the fractional-sample dead-time (theta_frac < Ts) and
50// returns a 1-state StateSpace you can absorb into a SmithPredictor model.
51//
52// Formula (Tustin-discretised continuous [1,1] Pade):
53// H_c(s) = (1 - 0.5.theta_frac.s) / (1 + 0.5.theta_frac.s)
54// This exactly matches the delay e^{-theta_frac.s} to first order.
55//
56// Ref: Vetter, "Numerical Continuation Methods" (1991);
57// Baker & Graves-Morris, "Pade Approximants" (1996);
58// Astrom & Wittenmark, "Computer Controlled Systems" Sec. 6.4 (1997).

40 // Bumpless initialisation - called by ControllerStack (Supervisory mode) when
41 // this controller is newly selected, so it produces u_target at the current error
42 // without an output bump.
43 //
44 // u_target: the output the composite loop is currently delivering.
45 // error: the current tracking error passed to compute().
46 //
47 // The default is a no-op (e.g., for stateless or non-integrating controllers).
48 // Override in controllers that have integral or memory state (PID, MPC, SMC).
49 //
50 // MIMO limitation: this interface is scalar. For MIMO controllers (e.g.,
51 // DiscreteMPC operating on a vector plant), the bumpless handover is a vector
52 // operation (initialise each input channel to match the corresponding u_target
53 // component). ControllerStack currently calls bumplessInit with a scalar
54 // (the single composite output from the previous step), which is only meaningful
55 // for the first output channel. MIMO controllers that need multi-channel
56 // bumpless transfer must implement it outside the IController interface, e.g.,
57 // by calling DiscreteMPC::setState() and DiscreteMPC::setLastApplied() directly
58 // from the switching logic before handing control to the new controller.
59 virtual void bumplessInit(double /*u_target*/, double /*error*/) {}

61 // Health query for supervisory fault-tolerant control.
62 //
63 // Returns false when the controller's last compute() call produced a result
64 // that is known to be suboptimal or potentially unsafe:
65 // - DiscreteLQR: DARE did not converge at construction.
66 // - DiscreteMPC: QP solver exited at qpMaxIter (last step did not converge).
67 // - GeneralizedPredictiveController: same as MPC.
68 //
69 // ControllerStack (Supervisory mode) checks isHealthy() before selecting an entry:

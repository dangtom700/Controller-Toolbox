Detailed Description

Nu-gap (Vinnicombe gap) metric for SISO discrete-time linear systems.

The nu-gap delta_nu(P1, P2) measures the distance between two plants' closed-loop behaviours on the Riemann sphere of transfer functions. A distance below 0.5 means a single robust controller can stabilise both plants simultaneously (Vinnicombe 2001, "Uncertainty and Feedback").

Implementation: Uses the frequency-domain chordal metric:

delta_nu(P1, P2) ~= sup_omega |P1(e^{j*omega*Ts}) - P2(e^{j*omega*Ts})|
/ sqrt((1 + |P1|^2) * (1 + |P2|^2))

over a log-spaced grid from omega_min to pi/Ts. This gives an upper bound on the exact nu-gap (which also requires a winding-number check). The upper bound is sufficient for clustering: if it is below the chosen threshold, a single robust controller works for the entire cluster.

Reference
Vinnicombe, G. (2001). Uncertainty and Feedback: H-infinity Loop-Shaping and the nu-Gap Metric. Imperial College Press.
Note
Only SISO (p=1, m=1) systems are accepted. For MIMO, extend using the subspace chordal distance (Skogestad & Postlethwaite Ch. 9).

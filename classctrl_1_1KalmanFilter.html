Combined predict + update - most common usage pattern.

Equivalent to calling predict(u_prev) followed by update(y, u_current).

Parameters
yMeasurement vector y[k].
u_prevControl input u[k-1] (predict step).
u_currentControl input u[k] (update step, D.u feedthrough). Defaults to nullopt, which falls back to u_prev - correct for D = 0 plants. For D != 0, pass the actual current input to avoid a one-step feedthrough bias.

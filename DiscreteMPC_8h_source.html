6// Discrete-time Model Predictive Controller (condensed incremental QP formulation).
7//
8// Cost: J = Sigma_{i=1}^{Np} rho_y.||y[k+i|k] - r||^2 + Sigma_{j=0}^{Nc-1} rho_u.||Deltau[k+j]||^2
9//
10// Prediction (condensed form):
11// Y_pred = F.x[k] + G_u.u_prev + Phi.DeltaU
12// F(i,:) = C.A^(i+1) i = 0,...,Np-1
13// G_u(i,:) = Sigma_{j=0}^{i} C.A^j.B (cumulative step response)
14// Phi(i,j,:) = C.A^(i-j).B j <= i, else 0
15//
16// Unconstrained optimal solution (receding horizon, apply first move only):
17// DeltaU* = -(Phi'.Q_y.Phi + R_u)^-^1.Phi'.Q_y.(F.x[k] - R_stacked)
18// u[k] = u[k-1] + DeltaU*[0:m]
19//
20// Box constraints on Deltau and u are solved via gradient projection (Lipschitz step 1/L,
21// L = max eigenvalue of H, precomputed once). Bounds for the first control step
22// are tightened to reflect both the Deltau limits and the absolute u limits simultaneously.
23// qpMaxIter / qpTol tune convergence; defaults are adequate for horizons Nc <= 20.
24//
25// Ref: Camacho & Bordons "Model Predictive Control" (2007);
26// Maciejowski "Predictive Control with Constraints" (2002);
27// MATLAB mpc(), mpcDesigner.

79 //
80 // Without this call, computeRef() advances x_hat_ using the MPC-commanded u
81 // (stored in u_prev_), not the physically applied input. After several
82 // consecutive saturations x_hat_ drifts silently from the real plant state,
83 // producing confident but wrong predictions. This is distinct from the
84 // open-loop drift documented at DiscreteMPC.cpp:203 (which is due to missing
85 // measurement feedback); this drift is caused by input mismatch at the actuator.
86 //
87 // Call pattern (each control step, after the allocator):
88 // VectorXd u_cmd = mpc.computeRef(x, ref); // MPC command
89 // VectorXd u_act = allocator.apply(u_cmd); // actuator may clip
90 // mpc.setLastApplied(u_act); // correct u_prev_ for next step
91 //
92 // If setState() is also called each step with a measurement-corrected estimate,
93 // these two calls together completely close the model-input loop.

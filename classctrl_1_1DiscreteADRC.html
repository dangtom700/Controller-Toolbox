◆ compute()

double ctrl::DiscreteADRC::compute ( double  error)
overridevirtual

IController wrapper: compute u[k] from tracking error e[k] = r - y.

Warning
Call setReference(r) once per cycle before calling compute(error). If setReference() is not called, r_ defaults to 0 and the controller will drive the plant output to zero regardless of the intended setpoint - a silent incorrect answer that is hard to diagnose inside a ControllerStack.

Internally recovers y = r_ - error and delegates to computeTracking(y, r_).

Parameters
errorTracking error e[k] = r[k] - y[k].
Returns
Saturated control output u[k].

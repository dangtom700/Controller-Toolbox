Detailed Description

EWMA chart: detects gradual trends and slow drifts.

Z[k] = lambda * x[k] + (1 - lambda) * Z[k-1]
UCL = mu0 + L * sigma * sqrt(lambda / (2 - lambda))
Alarm if |Z[k] - mu0| >= UCL_half_width

93 // ---------------------------------------------------------------------------
94 // c2d - discretise a continuous-time state-space model.
95 //
96 // The input StateSpace must carry Ts == 0.0 to indicate continuous time.
97 // Pass the desired sample period as the second argument.
98 //
99 // Methods:
100 // ZOH - zero-order hold (exact for piecewise-constant inputs).
101 // Uses the matrix-exponential embedding:
102 // M = expm([Ac Bc; 0 0] * Ts) -> Ad = M[:n,:n], Bd = M[:n,n:]
103 // Requires <unsupported/Eigen/MatrixFunctions>.
104 //
105 // Tustin - bilinear (Tustin) transform, s = (2/Ts)*(z-1)/(z+1).
106 // Ad = (I - alpha.Ac)^{-1}.(I + alpha.Ac) alpha = Ts/2
107 // Bd = Ts.(I - alpha.Ac)^{-1}.Bc
108 // Preserves stability but distorts frequency axis.
109 //
110 // Cd and Dd are unchanged for both methods.
111 //
112 // Equivalent MATLAB: c2d(sys_c, Ts, 'zoh') / c2d(sys_c, Ts, 'tustin')
113 // ---------------------------------------------------------------------------
114 // ---------------------------------------------------------------------------
115 // ss2tf - convert SISO discrete state-space model -> transfer function.
116 //
117 // Computes the denominator from the characteristic polynomial of A (via
118 // Faddeev-LeVerrier / Leverrier's algorithm) and the numerator from the
119 // Markov parameters h[0]=D, h[k]=C.A^{k-1}.B (k>=1):
120 //
121 // b[k] = Sigma_{j=0}^{k} a[j] . h[k-j] (a[0]=1, a[1..n] from char. poly)
122 //
123 // Only valid for SISO systems (stateSize() >= 1, inputSize() == outputSize() == 1).
124 // Throws std::invalid_argument for non-SISO plants.
125 //
126 // Convention note: the returned TransferFunction uses the z^{-1} polynomial form
127 // (see struct TransferFunction above). The denominator is monic: den[0] = 1
128 // (the leading z^n coefficient is normalised to 1). The coefficient vector is
129 // den = {1, a1, a2, ..., an} in z^{-1} powers: 1 + a1*z^{-1} + ... + an*z^{-n}
130 // If you pass this to an external tool that expects the unnormalised form
131 // {a_n, a_{n-1}, ..., a_0} (e.g., MATLAB tf() with explicit denominator vector),
132 // you must reverse the vector and note that the leading coefficient is already 1.
133 //
134 // Equivalent MATLAB: tf(sys) where sys is a discrete ss object.
135 // ---------------------------------------------------------------------------
136 TransferFunction ss2tf(const StateSpace &sys);

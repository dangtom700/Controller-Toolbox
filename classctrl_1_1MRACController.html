Detailed Description

Discrete-time MRAC controller - SISO, first-order reference model.

Implements IController with the ADRC output convention: compute(y_plant) takes the plant output (not the error). Call setReference(r) once per step before compute().

◆ compute()

double ctrl::MRACController::compute ( double  y_plant)
overridevirtual

Compute one control step.

Execution order:

  1. e_m = y - y_m[k] (model tracking error)
  2. u = clamp(theta_r.r + theta_y.y, uMin, uMax) (control law)
  3. theta_r, theta_y updated via gradient + sigma-mod (adaptation)
  4. ||theta|| projected if > theta_max
  5. y_m[k+1] = a_m.y_m + b_m.r (advance reference model)
Parameters
y_plantCurrent plant output y[k].
Returns
Control signal u[k].

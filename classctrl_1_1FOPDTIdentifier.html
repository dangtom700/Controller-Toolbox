IMC-PID tuning from a FOPDT model (Rivera 1986).

Yields a PID controller with:

Kp = (tau + theta/2) / (K * (lambdaC + theta/2))
Ti = tau + theta/2
Td = tau * theta / (2 * tau + theta) [set to 0 for PI mode]

Rule of thumb: lambdaC = (1..3) * max(theta, tau) gives moderate speed; lambdaC = theta/2 for aggressive response.

Parameters
modelIdentified FOPDT model.
lambdaCClosed-loop time constant [s]. Larger = more conservative.
TsController sample time [s].
piOnlyIf true, Td is set to zero (PI instead of PID).
Returns
DiscretePIDParams ready for DiscretePID construction.

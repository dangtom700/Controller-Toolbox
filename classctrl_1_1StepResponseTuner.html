Detailed Description

Open-loop step-response FOPDT identifier and PID tuner.

Fits a First-Order Plus Dead-Time (FOPDT) model to open-loop step-response data using the process-reaction-curve tangent method:

G(s) approx = K . e^{-thetas} / (taus + 1)

5// Perturbation-based Extremum Seeking Controller (ESC).
6//
7// Injects a sinusoidal dither into the plant operating point, demodulates the
8// plant output to extract a gradient estimate, then integrates the gradient to
9// converge to the extremum of an unknown static (or slowly varying) cost surface.
10//
11// Algorithm pseudocode (per sample k):
12//
13// phase[k] = phase[k-1] + 2*pi*f_p*Ts // phase accumulator (mod 2*pi)
14// dither[k] = a * sin(phase[k]) // perturbation signal
15// u[k] = theta[k] + dither[k] // total plant input
16//
17// // High-pass filter (backward-Euler first-order, cutoff f_hpf):
18// alpha_h = 1 / (1 + 2*pi*f_hpf*Ts)
19// y_h[k] = alpha_h * (y_h[k-1] + y[k] - y[k-1]) // removes DC/slow drift
20//
21// // Demodulate: multiply HPF output by reference dither to extract gradient phase
22// xi[k] = y_h[k] * sin(phase[k])
23//
24// // Low-pass filter (backward-Euler first-order, cutoff f_lpf):
25// alpha_l = 2*pi*f_lpf*Ts / (1 + 2*pi*f_lpf*Ts)
26// ghat[k] = ghat[k-1] + alpha_l * (xi[k] - ghat[k-1]) // gradient estimate
27//
28// // Gradient-descent (ascent) integration:
29// sign_dir = seekMinimum ? -1.0 : +1.0
30// theta[k+1] = theta[k] + sign_dir * k_int * Ts * ghat[k]
31//
32// Separation of timescales requirement:
33// plant settling time << 1/f_p << 1/(f_lpf)
34// so the plant responds quasi-statically to the dither and the LPF cleanly extracts
35// the gradient. Violating this produces a biased gradient estimate and slow/no convergence.
36//
37// Ref: Ariyur & Krstic "Real-Time Optimisation by Extremum-Seeking Control" (2003);
38// Tan et al. "On non-local stability of ESC" (2006);
39// Simulink Extremum Seeking block (MATLAB R2020b+).

Controller Toolbox

Discrete-time control library — C++17 · Eigen 3.4 · 20+ controllers · 8 tuning families

Overview

A single-include, header+source C++ library for discrete-time control design, system identification, state estimation, and robust synthesis. All controllers derive from a common IController interface and can be freely composed via ControllerStack.

Quick Start

#include "ControllerToolbox.h"

// 1. Define plant: G(s) = 1/(s+1), ZOH @ Ts=0.01s
ctrl::StateSpace G_c({ {-1},{1},{1},{0}, 0.0 });       // continuous-time
ctrl::StateSpace G_d = ctrl::c2d(G_c, 0.01);           // discrete ZOH

// 2. Tune PID (relay test or step response)
ctrl::StepResponseTuner::FOPDTModel m{ .K=1, .tau=1, .theta=0 };
ctrl::PIDParams pp = ctrl::StepResponseTuner::computePIDParamsFor<ctrl::DiscretePID>(
                         m, 0.01, ctrl::PIDTuningRule::IMC);

// 3. Create controller
ctrl::DiscretePID pid(pp, 0.01);

// 4. Run loop
double r = 1.0, y = 0.0;
ctrl::Eigen::VectorXd x = Eigen::VectorXd::Zero(1);
for (int k = 0; k < 500; ++k) {
    double u = pid.compute(r - y);
    y = ctrl::ssStep(G_d, x, Eigen::VectorXd::Constant(1, u))(0);
}

// 5. Extract metrics
// ... collect t_data, y_data ...
auto m = ctrl::MetricsAnalyzer::calculate(t_data, y_data, r);

DiscretePID

Algorithm

ISA parallel form with backward-Euler integrator and backward-Euler derivative filter:

alpha  = 1 / (1 + N*Ts)
d[k]   = alpha*d[k-1] + Kd*N*alpha*(e[k] - e[k-1])         // derivative filter
I[k]   = I[k-1] + Ki*Ts*e[k] + Kb*(u_sat[k-1] - u_unsat[k-1])  // anti-windup
u[k]   = Kp*e[k] + I[k] + d[k]                              // unsaturated output
u_sat  = clamp(u, uMin, uMax)

Anti-windup

Back-calculation: when output saturates, the integral term is corrected by Kb*(u_sat - u_unsat). Set Kb=0 to disable.

Bumpless transfer

bumplessInit(u_target, error) pre-loads the integral so the first compute() returns approximately u_target. Called automatically by ControllerStack on supervisory switching.

Parameters PIDParams

FieldDefaultMeaning
Kp1.0Proportional gain
Ki0.0Integral gain (Ki = Kp/Ti)
Kd0.0Derivative gain (Kd = Kp*Td)
N100Derivative filter pole [rad/s]. Higher = less filtering.
uMin / uMax±1e9Output saturation limits
Kb1.0Anti-windup back-calculation gain (0 = disabled)

Tuning methods

RelayAutoTuner · StepResponseTuner (IMC, ZN, Cohen-Coon, AMIGO) · ZieglerNicholsTuner · CohenCoonTuner

DiscreteLQR

Algorithm

Solves the Discrete Algebraic Riccati Equation (DARE) offline via the doubling algorithm (Pappas-Laub-Sandell 1980):

P_inf = A'*P*A - (A'*P*B)*(R + B'*P*B)^{-1}*(B'*P*A) + Q
K*    = (R + B'*P*B)^{-1} * B'*P*A
u[k]  = -K* * (x[k] - x_ref) + u_ff

The doubling algorithm converges quadratically (doubles correct digits per iteration); 30–50 iterations suffice for double precision, versus thousands for value iteration. Symmetry of P is enforced at every iteration to prevent LDLT failure on near-rank-deficient systems.

Pre-solve checks

  • PBH stabilisability: (A,B) — warns if any unstable mode is uncontrollable.
  • PBH detectability: (A,Q) — warns if any unstable mode has zero Q penalty.
DiscreteLQR expects full state feedback. For output feedback (partial or noisy observations), use DiscreteLQG which adds a Kalman filter.

Parameters LQRParams

FieldMeaning
QState cost matrix (n×n, PSD). Increase Q[i,i] to tighten control of state i.
RControl cost matrix (m×m, PD). Increase R[j,j] to limit input j.

Bryson's rule (starting point)

Q[i,i] = 1 / max_state_deviation[i]^2
R[j,j] = 1 / max_control_effort[j]^2
auto weights = ctrl::LQRWeightTuner::brysonMethodFor<ctrl::DiscreteLQR>(xmax, umax);

DiscreteLQG

Algorithm

Combines DiscreteLQR and KalmanFilter under the separation principle:

// Each step:
kf.predict(u[k-1])              // x^[k|k-1] = A*x^[k-1] + B*u[k-1]
kf.update(y[k], u[k-1])         // x^[k|k] from measurement (D=0 assumed)
u[k] = -K* * (x^[k|k] - x_ref)
Causal constraint: u[k] is not yet available when the Kalman update runs. For D=0 plants (standard ZOH discretisation) this is exact — the D*u term vanishes. For D≠0 plants, the update uses u[k-1] as an approximation; the constructor warns about this.

Separation principle

LQR weights (Q,R) and Kalman noise weights (Q_noise, R_noise) can be tuned independently:

auto lqr_w = ctrl::LQRWeightTuner::brysonMethodFor<ctrl::DiscreteLQG>(xmax, umax);
auto kf_w  = ctrl::KalmanWeightTuner::fromNoiseFor<ctrl::DiscreteLQG>(proc_noise, meas_noise);

DiscreteMPC

Condensed QP formulation

// Prediction: Y_pred = F*x + Gu*u_prev + Phi*DeltaU
// Cost:  min  ||Y_pred - R||^2_Qy  +  ||DeltaU||^2_Ru
// s.t.   duMin <= DeltaU <= duMax  (per step)
//        uMin  <= u_prev + sum(DeltaU_0..j) <= uMax  (rolling)

Solved by gradient projection with step size 1/L where L = λ_max(H). The Hessian H = Phi'*Qy*Phi + Ru is pre-factored via LDLT once at construction (or when horizons change); only the gradient changes each step.

The compute(error) wrapper reconstructs the reference as r = C*x̂ + error using an open-loop state estimate. This estimate drifts for plants with disturbances, model mismatch, or integrating modes. For reliable closed-loop behaviour, inject a Kalman estimate via setState(kf.state()) before each call to computeRef(x, r).

GeneralizedPredictiveController (GPC)

CARIMA velocity-form model

Augments the plant state as x_a = [Δx; y] so the integrating disturbance model is built in — no separate integral state is needed to reject step disturbances.

Aa = [A, 0; C*A, I]   Ba = [B; C*B]   Ca = [0, I]

Reference trajectory

y*[k+j] = alpha^j * y[k] + (1 - alpha^j) * r    (j = 1..Np)

alpha=0: step reference (same as MPC). alpha → 1: slow first-order approach. Typical: alpha = exp(-Ts/tau_ref).

GPC is better than standard MPC for processes with integrating or near-integrating dynamics (level control, velocity ramps). The velocity-form model handles offset without separate integral tuning.

DiscreteADRC (LADRC)

3rd-order Extended State Observer (ESO)

Models the plant as a double integrator with unknown total disturbance f:

y = f(y, ẏ, d, t) + b0*u    // b0 = approximate input gain

ESO estimates z₁≈y, z₂≈ẏ, z₃≈f. Bandwidth-parameterised:

beta1 = 3*omega_o   beta2 = 3*omega_o^2   beta3 = omega_o^3

Discretised with backward Euler (A-stable for all omega_o*Ts > 0):

z3_new = z3 + Ts*beta3*eps
z2_new = z2 + Ts*(beta2*eps + b0*u_prev) + Ts*z3_new
z1_new = z1 + Ts*beta1*eps              + Ts*z2_new
u0 = omega_c^2*(r - z1) - 2*omega_c*z2
u  = (u0 - z3) / b0
When using the IController::compute(error) wrapper: you must call setReference(r) before each compute() call. If omitted, r_ defaults to 0 and the controller will drive the plant output to zero regardless of setpoint. Use computeTracking(y, r) directly when possible.

Parameters ADRCParams

FieldTypicalMeaning
omega_o3–10× omega_cESO bandwidth [rad/s]. Must satisfy omega_o*Ts ≪ 1 for accuracy.
omega_c~BW of desired loopController bandwidth [rad/s]
b0plant input gainApproximate gain b in ÿ = f + b·u. For motors: b0 = Km/J.

DiscreteSMC / SuperTwistingSMC

Sliding surface

s[k] = c_e*e[k] + c_de*(e[k] - e[k-1])

DiscreteSMC — boundary-layer (1st order)

u[k] = -K * sat(s[k] / phi)
sat(x) = x       if |x| ≤ 1    // PD inside boundary layer
sat(x) = sign(x) if |x| > 1    // relay switching outside

phi → 0: ideal chattering SMC. phi large: smooth PD approximation.

SuperTwistingSMC — 2nd order (no chattering)

u[k]   = v[k] - K1*|s|^0.5 * sign(s)    // power term
v[k+1] = v[k] - K2*Ts * sign(s)          // integral term (Euler)

Sufficient gain condition: K1 > 0, K2 > K1²/4. Keep K2*Ts ≪ K1 to limit discretisation error.

Note on c_de

c_de absorbs the sample time. To match a continuous-time sliding-surface slope λ [1/s], set c_de = lambda * Ts.

DiscreteLeadLag

Algorithm

Tustin discretisation of C(s) = K·(s+z_c)/(s+p_c):

b0 = K*(2/Ts + z_c) / (2/Ts + p_c)
b1 = K*(z_c - 2/Ts) / (2/Ts + p_c)
a1 = (p_c - 2/Ts)   / (2/Ts + p_c)
y[k] = b0*u[k] + b1*u[k-1] - a1*y[k-1]

Lead (p_c > z_c): adds positive phase, improves phase margin. Lag (p_c < z_c): boosts low-frequency gain.

phaseAt(omega) uses the continuous-time formula. Accuracy degrades near the Nyquist frequency due to Tustin frequency warping.

SmithPredictor

Algorithm

Compensates for pure integer dead-time d steps:

e_sp[k] = (r[k] - y[k]) + (ŷ[k] - ŷ[k-d])    // modified error
u[k]    = inner.compute(e_sp[k])
ŷ updated via delay-free model P0 with u[k]
Model must be delay-free: pass the plant model without the dead-time lag. The predictor adds the delay compensation internally.
For fractional dead-times (theta not a multiple of Ts), round to the nearest integer and apply a first-order Padé approximant to the fractional remainder. This is not currently built in; implement it externally or absorb the error into the inner controller tuning.

Use setModel() to hot-swap the internal model for adaptive Smith predictors (e.g., paired with RLS identification).

RepetitiveController

Learning law

v[k]  = Q * v[k-N] + Krc * e[k]    // circular buffer of length N
u[k]  = u_base[k] + v[k]           // plug-in addition

v_buf_ stores one full period of corrections. Each slot is overwritten by the current step's updated correction, ready to be read N steps later.

QEffect
1.0Perfect memory — converges to exact cancellation; zero robustness margin to period mismatch
0.95–0.99Exponential forgetting — slightly slower convergence, tolerates period uncertainty

Stability condition (sufficient, SISO): Q / |1 + L(e^jω)P(e^jω)| < 1 for all ω.

ExtremumSeeker

Signal chain

d[k]   = a * sin(phase)               // dither
u[k]   = theta[k] + d[k]             // plant input
y_h[k] = HPF(y[k])                   // remove DC
xi[k]  = y_h[k] * sin(phase)         // coherent demodulation
ĝ[k]   = LPF(xi[k])                 // gradient estimate
theta += sign * k_int * ĝ * Ts       // integrate toward extremum

Phase accumulates as phase = fmod(phase + 2π*fp*Ts, 2π), preventing floating-point drift at large step counts.

Frequency separation requirement: ω_plant ≪ ω_p ≪ 1/(Ts·N_filter). If the dither frequency is too close to the plant bandwidth, the gradient estimate is corrupted.

DiscreteHinf

DGKF two-Riccati synthesis

Synthesises K(z) minimising ‖F_l(P,K)‖∞ < γ via bisection on γ.

// 1. Build augmented plant (MixedSensitivity for S/KS/T design)
auto P = ctrl::MixedSensitivity::build(G, W1, W2, W3);

// 2. Synthesise
ctrl::HinfParams hp; hp.gammaInit = 5.0; hp.gammaTol = 0.01;
auto result = ctrl::DiscreteHinf::solve(P, hp);

// 3. Use controller
if (result.feasible) {
    ctrl::DiscreteHinf K(result);
    double u = K.compute(y_measurement);
}
D22 constraint: the standard DGKF formulas assume D22 = 0. If the generalised plant has nonzero D22, the synthesised controller is incorrect. MixedSensitivity::build() guarantees D22 = 0 for the standard S/KS/T problem. For custom plant constructions, verify P.D22.isZero(1e-12).

KalmanFilter (Linear)

Update equations (Joseph form)

// Predict
x^[k|k-1] = A*x^[k-1] + B*u[k-1]
P[k|k-1]  = A*P*A' + Q

// Update
S   = C*P*C' + R            // innovation covariance
Kf  = P*C' * S^{-1}         // Kalman gain (solved via LDLT)
x^  += Kf * (y - C*x^ - D*u)
// Joseph form (numerically superior to basic form):
P   = (I-Kf*C)*P*(I-Kf*C)' + Kf*R*Kf'

The Joseph form maintains positive-semidefiniteness even with round-off, unlike the standard (I-KC)*P update.

For D=0 plants, pass the same u as both u_prev and u_current in step(). For D≠0 plants, pass the actual current control input to avoid a one-step stale feedthrough bias.

ExtendedKalmanFilter (EKF)

Key difference from KF

Linearises nonlinear f and h at each step. State propagation uses the exact nonlinear function; only the covariance uses the Jacobian:

F[k] = df/dx|_{x^[k|k],u[k]}     // for P predict
H[k] = dh/dx|_{x^[k+1|k],u[k]}   // for Kalman gain

Jacobians can be supplied analytically or computed automatically via central-difference:

auto Fjac = [&](const Eigen::VectorXd& x, const Eigen::VectorXd& u) {
    return ctrl::ExtendedKalmanFilter::numericalJacobian(
        [&](const Eigen::VectorXd& xx){ return f(xx, u); }, x);
};
Numerical Jacobians cost 2n function evaluations each step. For real-time systems with n > 10, derive analytical Jacobians.

UnscentedKalmanFilter (UKF)

No Jacobians required

Propagates 2n+1 sigma points through the exact nonlinear functions, capturing mean and covariance to 3rd order (vs. EKF's 1st order). Better accuracy for highly nonlinear systems.

lambda = alpha^2*(n+kappa) - n
X_0 = x^,   X_i = x^ ± sqrt((n+lambda)*P)_i  (i=1..n)
Covariance PSD: the UKF covariance update P -= K*Syy*K' can lose positive-semidefiniteness with round-off (unlike the linear KF's Joseph form). A negative-eigenvalue floor is applied automatically after each update step.

Parameters

ParamDefaultEffect
alpha1e-3Sigma-point spread. Smaller = tighter cluster around mean.
beta2.0Prior distribution; 2 is optimal for Gaussian.
kappa0.0Secondary scaling; use 0 or 3-n.

RecursiveLeastSquares (RLS)

ARX online identification

// ARX model: y[k] = -a1*y[k-1] - ... + b1*u[k-1] + ...
phi[k] = [-y[k-1],...,-y[k-na], u[k-1],...,u[k-nb]]'
// RLS update:
K     = P*phi / (lambda + phi'*P*phi)    // Kalman gain
e     = y - phi'*theta                   // a-posteriori error
theta += K*e                             // parameter update
P     = (P - K*phi'*P) / lambda          // covariance — /lambda is forgetting

The / lambda in the covariance update is not a typo: it inflates P at each step, giving more weight to recent data. With lambda=1, P monotonically shrinks (standard LS — no tracking).

toTransferFunction() prepends b0=0 to the numerator (ARX has no direct feedthrough). The output D matrix of the resulting state-space will always be zero for a pure delay-≥1 ARX model.

Practical choices

Use caselambda
Time-invariant plant1.0
Slowly varying plant0.97–0.99
Fast-changing plant0.90–0.95

SubspaceID (N4SID / MOESP)

Algorithm steps

1. Build 2i-block Hankel matrices Z from (Y, U)
2. Thin LQ decomposition of Z → extract block L32 (oblique projection)
3. SVD(L32) → system order n, extended observability matrix Gamma
4. C = Gamma[:p, :],   A from shift-invariance of Gamma (LS)
5. B, D from state-sequence regression (LS)
6. Kalman gain K and innovation covariance from residuals

Order selection

// Run with large n first, inspect singular values:
auto res = ctrl::n4sid(Y, U, 20, i_horizon, Ts);
int n = ctrl::suggestOrder(res.singularValues);   // automatic elbow detection
res  = ctrl::n4sid(Y, U, n, i_horizon, Ts);       // rerun with chosen order

Using the identified Kalman gain

// Skip manual Q/R tuning — use what n4sid extracted:
ctrl::KalmanFilter kf(res.model.value(), /*Q=*/res.kalmanGain * res.innovCov * res.kalmanGain.transpose(),
                                          /*R=*/res.innovCov);

Numerics Notes

DARE symmetry

The LQR doubling algorithm enforces X = 0.5*(X+X') at every iteration to suppress asymmetry drift. Without this, LDLT on the Schur complement can fail with NumericalIssue on near-rank-deficient plants.

Joseph-form covariance

Both KF and EKF use P = (I-KC)*P*(I-KC)' + K*R*K'. The UKF uses P -= K*Syy*K' (unavoidable — no explicit H matrix), with an eigenvalue floor applied afterward to maintain PSD.

RLS numerator prepend

ARX models have no direct feedthrough (B-polynomial starts at z⁻¹). toTransferFunction() prepends b₀=0 before passing to tf2ss(). Without this, tf2ss would interpret b₁ as the D term.

Innovation covariance floor

All Kalman-family update steps clamp R.diagonal() = R.diagonal().cwiseMax(1e-12) before computing the Schur complement, preventing near-singular S when measurement noise is unrealistically small.

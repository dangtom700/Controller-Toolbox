Detailed Description

Discrete first-order Sliding Mode Controller with boundary-layer saturation.

Sliding surface:

s[k] = c_e·e[k] + c_de·(e[k] − e[k−1])

Control law (sat replaces sign to reduce chattering):

u[k] = −K·sat(s[k] / φ)
sat(x) = x if |x| ≤ 1 (linear PD inside the boundary layer)
sat(x) = sign(x) if |x| > 1 (relay switching outside)

Setting φ → 0 recovers ideal relay SMC with chattering. Setting φ large gives a soft PD approximation.

Detailed Description

Discrete-time Plug-in Repetitive Controller (RC).

Cancels periodic references and disturbances with known period T = N·Ts by wrapping any existing IController (base) and adding a learned periodic correction:

v[k] = Q·v[k−N] + Krc·e[k] (repetitive learning law)
u[k] = u_base[k] + v[k] (plug-in addition to base controller output)

v is a circular buffer of length N. Each element accumulates over periods:

  • Q = 1: perfect cancellation after sufficient learning, zero robustness margin.
  • Q < 1: exponential forgetting; suppresses model-mismatch instability.

Stability condition (sufficient, SISO linear base): The closed loop with the base controller must be stable, and Q / |1 + L(e^jω)·P(e^jω)| < 1 for all ω (internal model robustness test).

// Typical usage
auto pid = std::make_shared<ctrl::DiscretePID>(pp, Ts);
auto rc = ctrl::RepetitiveController(pid, {100, 0.5, 0.98}, Ts);
double u = rc.compute(error); // replaces pid.compute(error)

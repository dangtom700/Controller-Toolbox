Detailed Description

Parameters for mu-synthesis via DK-iteration.

DK-iteration alternates between:

  • K-step: H-infinity synthesis on the D-scaled plant.
  • D-step: Amplitude-balance D-scaling that minimises an upper bound on the structured singular value mu over a frequency grid.

The D-scaling is held constant (frequency-independent), which avoids rational-function fitting of D(jw) while still providing a tighter mu bound than plain H-infinity. The resulting controller satisfies:

mu_upper <= sigma_max(D * F_l(P, K)(jw) * D^{-1}) for all w

where D is an element-wise positive diagonal scaling found by the amplitude-balance algorithm (Sinkhorn-Knopp style).

Note
For full DK-iteration with frequency-dependent rational D(jw) fitting, the D-step requires an additional Pade/curve-fit pass per element - this is a planned extension (see cumulative_bug_report.md Part 17).

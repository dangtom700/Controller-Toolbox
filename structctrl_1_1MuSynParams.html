Detailed Description

Parameters for mu-synthesis via DK-iteration.

DK-iteration alternates between:

  • K-step: H-infinity synthesis on the D-scaled plant.
  • D-step: Amplitude-balance D-scaling that minimises an upper bound on the structured singular value mu over a frequency grid.

When useRationalD is false (default), D-scaling is held constant (frequency-independent) via Sinkhorn-Knopp amplitude balance.

When useRationalD is true, a first-order rational filter D_j(z) is fitted per diagonal element from the per-frequency amplitude-balance data. The plant is then augmented with these filters before the next K-step. This provides a tighter mu bound at the cost of a larger augmented plant.

mu_upper <= sigma_max(D(jw) * F_l(P, K)(jw) * D(jw)^{-1}) for all w
See also
Skogestad & Postlethwaite, "Multivariable Feedback Design" Ch. 8.12.
MATLAB dksyn() for the reference algorithm with vector-fitting D(jw).

◆ dFitOrder

int ctrl::MuSynParams::dFitOrder = 1

Order of the rational D-scaling filters (number of poles per channel).

  • 1 (default): first-order heuristic (fitFirstOrderDFilter) - fast, two data points.
  • >= 2: full vector-fitting (VectorFitting::fitMagnitude) - accurate multi-peak profile.

Only used when useRationalD is true.

8// Discrete-time Linear Quadratic Regulator (LQR).
9//
10// Offline: solves the Discrete Algebraic Riccati Equation (DARE) via value iteration.
11// Pinf = A'PinfA - (A'PinfB)(R + B'PinfB)^-^1(B'PinfA) + Q
12// K* = (R + B'PinfB)^-^1 B'PinfA
13//
14// Online: u[k] = -K*.(x[k] - x_ref) + u_ff
15//
16// For output feedback, first reconstruct the state with an observer (e.g., Kalman filter)
17// before calling compute().
18//
19// Ref: Anderson & Moore "Optimal Control" (1990);
20// MATLAB dlqr(), Simulink Optimal LQR Controller block.
21namespace ctrl
22{

24 // Result returned by the DARE solver - carries the solution, convergence flag, and
25 // iteration count so callers can decide whether to accept an approximate result.
26 struct DareResult
27 {

46 // Warns to stderr if DARE does not converge; uses the best available iterate.
47 //
48 // PBH rank test note: stabilisability and detectability are checked at construction
49 // using Eigen's fullPivLu().rank(), which applies an automatic rank threshold scaled
50 // by max_singular_value * n * epsilon. For plants with eigenvalues very close to the
51 // unit circle (e.g., poles at 0.9999 or 1.0001), this threshold may misdeclassify the
52 // system as non-stabilisable. If you suspect a false PBH failure, tighten the plant
53 // model or manually verify the PBH condition: rank([A - lambda*I, B]) == n for all
54 // |lambda| >= 1.

57 // Compute u[k] = -K*(x - x_ref) + u_ff.
58 // x_ref and u_ff default to zero when empty.
59 //
60 // Note: DiscreteLQR is stateless at runtime (no internal memory between compute() calls).
61 // If the returned u[k] is clamped by an external actuator before it reaches the plant,
62 // the state x[k+1] will evolve under the saturated input. For closed-loop correctness,
63 // always pass the ACTUAL plant state x[k] (from a sensor or state observer) to compute()
64 // rather than integrating the plant model with the unsaturated u[k]. This is the standard
65 // closed-loop correction mechanism: the observer implicitly corrects for saturation via
66 // the measurement update. For explicit anti-windup in state-feedback loops, see the
67 // discussion in Astrom & Wittenmark §9.3.
68 Eigen::VectorXd compute(const Eigen::VectorXd &x,

double ctrl::SystemAnalysis::calculateHInfinityNorm ( const StateSpace &  sys)
static

Compute the peak Hinf norm of a state-space model.

For SISO plants, equals the peak frequency-response magnitude. For MIMO plants, equals the peak induced L2-gain (maximum singular value over all frequencies).

Uses a coarse grid followed by golden-section search; typical accuracy is better than 0.1%.

Parameters
sysDiscrete-time state-space model.

StabilityMargins ctrl::SystemAnalysis::calculateMargins ( const StateSpace &  sys)
static

Compute gain and phase margins for a SISO open-loop plant.

Algorithm: coarse logarithmic grid (200 points) to bracket crossings, followed by bisection (50 iterations) for accuracy. Phase is continuously unwrapped across grid points, so the result is correct for higher-order and non-minimum-phase plants where phase can cross -180^\circ multiple times. Returns the worst-case (smallest) margin when multiple crossings exist.

Parameters
sysSISO discrete-time state-space model.
Returns
StabilityMargins with GM, PM, and crossover frequencies.

Compute the frequency response G(e^{jomegaTs}) at each frequency in freqs.

Uses the direct formula G(z) = C.(z.I - A)^-^1.B + D at z = e^{jomegaTs}. SISO only; throws for MIMO plants.

Eigen::MatrixXd ctrl::SystemAnalysis::solveDiscreteLyapunov ( const Eigen::MatrixXd &  A,
const Eigen::MatrixXd &  Q 
)
static

Solve the discrete Lyapunov equation A.P.Aᵀ - P + Q = 0.

Solved via Kronecker product vectorisation: (I - A\otimesA).vec(P) = vec(Q).

Complexity note
O(n⁶) due to the n^2*n^2 linear system - suitable for n <= 10. For n > 10, the Bartels-Stewart algorithm (O(n^3) via Schur decomposition) is strongly preferred; MATLAB's dlyap() uses Bartels-Stewart internally.
Parameters
ASystem matrix (must be strictly stable; unstable A gives a singular system).
QSymmetric positive semi-definite matrix (same dimensions as A).
Returns
Solution P.
See also
Golub, Nash & Van Loan, "A Hessenberg-Schur method for AX+XB=C", IEEE TAC (1979).

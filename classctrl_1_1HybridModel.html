Detailed Description

Hybrid plant model: physics + data-driven additive correction.

f_phys is integrated with RK4 over rk4_steps substeps. f_data is a discrete-time state correction (same units as x) added after integration.

Both functions must return Eigen::VectorXd of size n_states.

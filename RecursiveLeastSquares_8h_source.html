5// Discrete-time Recursive Least Squares (RLS) - SISO ARX system identification.
6//
7// Identifies a discrete-time ARX model online from I/O data:
8// A(q)y[k] = B(q)u[k] + e[k]
9// y[k] = -a1.y[k-1] - ... - ana.y[k-na]
10// + b1.u[k-1] + ... + bnb.u[k-nb] + e[k]
11//
12// Regressor: phi[k] = [-y[k-1],...,-y[k-na], u[k-1],...,u[k-nb]]' (na+nb * 1)
13// Parameters: theta = [a1,...,ana, b1,...,bnb]'
14//
15// Recursive update (directional forgetting via scalar lambda):
16// K[k] = P[k-1].phi[k] / (lambda + phi[k]'.P[k-1].phi[k])
17// e[k] = y[k] - phi[k]'.theta[k-1] (a-posteriori prediction error)
18// theta[k] = theta[k-1] + K[k].e[k]
19// P[k] = (P[k-1] - K[k].phi[k]'.P[k-1]) / lambda
20//
21// Forgetting factor lambda \in (0,1]:
22// lambda = 1 -> standard least squares (weights all data equally)
23// lambda < 1 -> exponential forgetting; effective window ~ 1/(1-lambda) samples
24// Typical: lambda = 0.95..0.99 for slowly time-varying plants.
25//
26// After sufficient excitation, call toTransferFunction() or toStateSpace()
27// to extract a model for use with DiscreteMPC, DiscreteLQG, etc.
28//
29// Ref: Astrom & Wittenmark "Adaptive Control" (1995) Ch.2;
30// Ljung "System Identification" (1999) Section 11.2.

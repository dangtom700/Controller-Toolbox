7// Discrete-time Plug-in Repetitive Controller.
8//
9// Cancels periodic references and disturbances with known period T = N.Ts.
10// Wraps any existing IController (base) and adds a learned periodic correction:
11//
12// v[k] = Q . v[k-N] + Krc . e[k] (repetitive learning law)
13// u[k] = u_base[k] + v[k] (plug-in addition)
14//
15// v is a circular buffer of length N; each element accumulates over periods.
16// After M periods the stored correction cancels the periodic disturbance exactly
17// (Q = 1) or with exponential forgetting (Q < 1, better robustness to model error).
18//
19// Parameters:
20// periodSteps (N): disturbance/reference period in samples = T/Ts (integer).
21// Krc: learning gain. Small -> slow but stable. Typical: 0.3..0.8.
22// Q: forgetting/robustness factor \in (0,1].
23// Q = 1 -> perfect cancellation, zero robustness margin.
24// Q < 1 -> exponential decay; suppresses model-mismatch instability.
25// Typical: 0.95..1.0.
26//
27// Stability condition (sufficient, SISO, linear base):
28// The closed-loop with the base controller must be stable, AND
29// Q / |1 + L(e^jomega).P(e^jomega)| < 1 for all omega (internal model robustness test).
30//
31// Usage:
32// auto pid = std::make_shared<ctrl::DiscretePID>(pp, Ts);
33// auto rc = ctrl::RepetitiveController(pid, N, 0.5, 0.98, Ts);
34// double u = rc.compute(error); // replaces pid.compute(error)
35//
36// Ref: Hara et al. "Repetitive Control System: A New Type Servo System" (1988);
37// Longman "Iterative Learning and Repetitive Control" (2000).

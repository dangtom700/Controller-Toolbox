Detailed Description

Discrete-time plant model representations and utilities.

Provides TransferFunction and StateSpace data structures, plus conversion and simulation utilities (tf2ss, ss2tf, ssStep, c2d, minreal) that parallel MATLAB's control toolbox.

See also
MATLAB tf(), ss(), tf2ss(), c2d() documentation.

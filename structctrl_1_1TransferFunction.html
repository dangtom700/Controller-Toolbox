Detailed Description

Discrete-time transfer function in z^-^1 polynomial form.

H(z^-^1) = (b0 + b1.z^-^1 + ... + bm.z^-^m)
-----------------------------
(1 + a1.z^-^1 + ... + an.z^-^n)

Equivalent MATLAB: ‘G = tf(num, den, Ts, 'Variable’, 'z^-1')`

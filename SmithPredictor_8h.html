Detailed Description

Smith Predictor — compensates for pure dead-time in discrete plants.

Replaces the dead-time delay in the feedback path with a prediction from an internal model, so the inner controller C(z) sees a delay-free loop.

Modified error delivered to the inner controller:

e_sp[k] = (r[k] − y[k]) + (ŷ_model[k] − ŷ_model[k−d])
= error + (current model output − d-step-delayed model output)

Requirements: the delayModel must represent the delay-**free** plant P₀(z).

Fractional dead-time support: If the true dead time θ is not an integer multiple of Ts, pass a first-order Padé filter (from FunctionApproximator::padeDelayFilter()) for the sub-sample remainder. The filter H_frac is connected in series with the delay model so the effective model is P₀_eff(z) = H_frac(z)·P₀(z), matching e^{−θ_frac·s} to first order without rounding.

See also
Smith, "Closed control of loops with dead time", Chem. Eng. Prog. 53 (1957).
Åström & Wittenmark, "Computer Controlled Systems" §6.4.

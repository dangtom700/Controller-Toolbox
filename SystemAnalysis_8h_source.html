32 // Solves the discrete Lyapunov equation: A * P * A' - P + Q = 0
33 // via Kronecker product vectorisation: (I - A\otimesA) * vec(P) = vec(Q).
34 // Complexity: O(n^6) due to the n^2 x n^2 linear system - suitable for n <= 10.
35 // At n=15 this is ~170 million flops; at n=20 it is ~1.6 billion.
36 // For n > 10, prefer the Bartels-Stewart algorithm (Golub, Nash & Van Loan 1979),
37 // which reduces complexity to O(n^3) via a Schur decomposition. MATLAB's dlyap()
38 // uses Bartels-Stewart internally for this reason.
39 // The Kronecker approach is retained here for simplicity (single Eigen solve,
40 // no custom Schur loop), but be aware of the performance cliff for larger systems.
41 // A must be strictly stable; an unstable A gives a singular (I - A\otimesA).
42 // Ref: Bartels & Stewart "Solution of the Matrix Equation AX + XB = C" CACM (1972);
43 // Golub, Nash & Van Loan "A Hessenberg-Schur method for AX+XB=C" IEEE TAC (1979).
44 static Eigen::MatrixXd solveDiscreteLyapunov(const Eigen::MatrixXd &A,
45 const Eigen::MatrixXd &Q);
46
47 // Frequency response G(e^{j*w*Ts}) at each frequency in freqs [rad/s].
48 // SISO only (1 input, 1 output); throws for MIMO plants.
49 // Uses the direct formula: G(z) = C*(z*I - A)^{-1}*B + D at z = e^{j*w*Ts}.
50 static std::vector<std::complex<double>> getFrequencyResponse(const StateSpace &sys,

53 // Gain and phase margins for a SISO open-loop plant.
54 // Algorithm: coarse logarithmic grid (200 pts) to bracket crossings, then
55 // bisection (50 iterations) for accuracy. Phase is continuously unwrapped
56 // across grid points, so the result is correct for higher-order and
57 // non-minimum-phase plants where the phase can pass through -180 deg multiple times.
58 // Returns the worst-case (smallest) margin when multiple crossings exist.

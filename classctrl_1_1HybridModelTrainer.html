Train the data component and install it in model.

Computes residuals delta_x_k = X_next_obs.col(k) - model.predictPhys(x_k, u_k) then fits the chosen model type on feature [x; u] -> delta_x.

Parameters
modelHybridModel to update (in-place via setDataModel()).
X_obsState observations at step k (n_states x N, column-major).
U_obsInput observations at step k (n_inputs x N).
X_next_obsTrue next states (n_states x N).
Returns
Result struct with success flag and training RMSE.

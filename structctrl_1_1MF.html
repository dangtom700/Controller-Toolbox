Detailed Description

Value-type tagged-union membership function.

Replaces std::function<double(double)> to eliminate heap allocation in the RT inference hot path. std::function stores closures on the heap for captures > ~16 bytes (implementation-defined SBO threshold), making it unsafe for hard-RT use. MF is a plain struct (sizeof <= 5 doubles) that is trivially copyable and stack-allocatable.

Use the factory functions (mfTriangular, mfTrapezoidal, etc.) to construct properly typed MF instances - the public API is identical to a callable except that MF is a concrete value type, not a type-erased callable.

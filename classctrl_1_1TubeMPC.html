Detailed Description

Tube MPC - robust IController for plants with bounded additive disturbances.

Requires setState() and setReference() before each compute() call, mirroring the NonlinearMPC API.

const TubeMPCParams &  p

Construct Tube MPC for a linear discrete-time plant.

Computes the mRPI set Z and the tightened constraints at construction. Factored Hessian and condensed matrices are precomputed here (O(Np^2.n^2.m)).

Parameters
sysDiscrete-time state-space model. Must have Ts > 0.
pTube-MPC parameters.
Exceptions
std::invalid_argumentIf dimensions are inconsistent or K is not stabilising (checked via spectral radius test: rho(A+BK) >= 1).

Scalar IController wrapper (SISO plants only).

Interprets error as the scalar tracking error e = r - y and calls setState+setReference using internally stored x and r = y+error. setState() MUST have been called this step for x to be known.

Detailed Description

FuzzyPD extended with a crisp integral term and back-calculation anti-windup.

Architecture - three decoupled blocks:

u_P = FuzzyPD(e, de)
u_I += Ki * Ts * e + Kb * (u_sat - u_unsat) // back-calculation anti-windup
u = clamp(u_P + u_I, uMin, uMax)
ctrl::FuzzyPD
5-term PD fuzzy controller implementing IController.

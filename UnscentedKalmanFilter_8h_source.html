5// Discrete-time Unscented Kalman Filter (UKF).
6//
7// Handles nonlinear systems WITHOUT requiring Jacobians:
8// x[k+1] = f(x[k], u[k]) + w[k], w ~ N(0, Q_noise)
9// y[k] = h(x[k], u[k]) + v[k], v ~ N(0, R_noise)
10//
11// NOISE MODEL ASSUMPTION: process and measurement noise are ADDITIVE (as above).
12// For multiplicative or state-dependent noise (e.g. gyroscope scale-factor noise,
13// Poisson photon counts), the correct formulation augments the state vector with the
14// noise channels and propagates augmented sigma points. That form is NOT implemented
15// here. If your system requires it, augment the state manually before constructing
16// the filter.
17//
18// Uses the Unscented Transform: propagates 2n+1 deterministically chosen
19// sigma points through the exact nonlinear functions to capture mean and
20// covariance to third order (vs. EKF's first-order linearisation).
21//
22// Sigma points (scaled UT, Wan & Van der Merwe 2000):
23// X_0 = x^
24// X_i = x^ + (sqrt((n+lambda).P))_i i = 1..n
25// X_{n+i} = x^ - (sqrt((n+lambda).P))_i i = 1..n
26// lambda = alpha^2.(n + kappa) - n
27//
28// Weights:
29// Wm_0 = lambda/(n+lambda), Wc_0 = lambda/(n+lambda) + (1 - alpha^2 + beta)
30// Wm_i = Wc_i = 1/(2(n+lambda)) i = 1..2n
31//
32// Recommended tuning: alpha=1e-3, beta=2 (Gaussian prior), kappa=0.
33//
34// Alpha sensitivity for large state dimensions:
35// alpha = 1e-3 is the Wan & Van der Merwe default, appropriate for n <= 3.
36// For larger n, the zeroth covariance weight Wc_0 = lambda/(n+lambda) + (1-alpha^2+beta)
37// becomes large and negative (e.g., Wc_0 ~ -6e6 for n=6 with alpha=1e-3).
38// This is mathematically valid but amplifies numerical noise in the covariance update.
39// For n >= 4, increase alpha toward 0.1..1.0 to keep |Wc_0| within [-n, 0]:
40// alpha = sqrt((kappa + n) / n) gives Wc_0 = 0 (minimum noise amplification).
41// The eigenvalue floor (1e-10*trace(P)) in update() is a backstop, not a substitute
42// for a well-tuned alpha. Verify Wc_0 is reasonable after construction.
43//
44// Ref: Wan & Van der Merwe, "The Unscented Kalman Filter for Nonlinear
45// Estimation", Proc. IEEE ASSPCC 2000;
46// Julier & Uhlmann, "A New Extension of the Kalman Filter" (1997).

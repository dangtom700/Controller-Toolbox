Detailed Description

Fitted SINDy model: xdot = Theta(x,u) .

Ξ.

Returned by SINDy::fit(). Acts as an opaque black-box; use stateFunc() to get a StateFunc lambda for use with NonlinearMPC / EKF / UKF.

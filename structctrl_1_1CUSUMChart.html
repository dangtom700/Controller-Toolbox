Detailed Description

CUSUM chart: detects sustained upward and downward mean shifts.

Two-sided CUSUM:

C_plus[k] = max(0, C_plus[k-1] + (x - mu0 - k_slack))
C_minus[k] = max(0, C_minus[k-1] - (x - mu0 + k_slack))
Alarm if C_plus >= h OR C_minus >= h

Detailed Description

Rational function approximator (Padé / Sanathanan–Koerner least squares).

Fits f(x) ≈ P(x)/Q(x), deg(P) = m, deg(Q) = n, Q(0) = 1. The denominator normalisation avoids the trivial all-zero solution of the unconstrained bilinear problem.

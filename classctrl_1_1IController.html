Detailed Description

Abstract interface for all discrete-time controllers.

All implementations operate at a fixed sample time Ts and are called once per step. The interface covers both SISO (compute()) and MIMO (computeVec()) controllers, bumpless initialisation for supervisory switching, and a runtime health query used by ControllerStack to implement automatic fallback chains.

See also
MATLAB Control System Toolbox discrete controller pattern.

void ctrl::IController::attachObserver ( IControllerObserver *  obs)

Attach a telemetry observer.

The observer receives onCompute() / onComputeVec() / onReset() callbacks after the corresponding methods fire. Only one observer is supported at a time; attaching a second replaces the first.

The observer is a non-owning raw pointer and must outlive the controller. Call detachObserver() before the observer is destroyed.

Parameters
obsPointer to the observer; may be nullptr to detach.

Bumpless initialisation - prepares the controller for smooth activation.

Called by ControllerStack (Supervisory mode) when this controller is newly selected, so its first compute() call returns u_target at the current error without a bump.

The default is a no-op; override in controllers that have integral or memory state (DiscretePID, DiscreteMPC, DiscreteSMC).

Parameters
u_targetThe composite output the loop is currently delivering.
errorThe current tracking error that will be passed to compute().
Note
MIMO limitation: this interface is scalar. For MIMO controllers that need multi-channel bumpless transfer, implement it outside IController (e.g., call DiscreteMPC::setState() / setLastApplied() directly before handing over).

Reimplemented in ctrl::DiscretePID, and ctrl::FuzzyPID.

◆ isHealthy()

virtual bool ctrl::IController::isHealthy ( ) const
inlinevirtual

Health query for supervisory fault-tolerant control.

Returns false when the controller's last compute() call produced a result known to be suboptimal or potentially unsafe:

  • DiscreteLQR: DARE did not converge at construction.
  • DiscreteMPC: QP solver hit qpMaxIter (last step did not converge).
  • GeneralizedPredictiveControl: same as MPC.

ControllerStack (Supervisory mode) checks isHealthy() before selecting an entry; an unhealthy controller is skipped in favour of the next eligible entry, enabling automatic fallback: MPC -> GPC -> PID when the QP consistently fails.

The default returns true. Override only in controllers with meaningful runtime health state.

Returns
true if the last computation was nominal; false if suboptimal.

Reimplemented in ctrl::LQRAdapter, ctrl::DiscreteMPC, and ctrl::GeneralizedPredictiveController.

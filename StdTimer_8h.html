Detailed Description

ITimer implementation using std::chrono::steady_clock.

Suitable for simulation, unit tests, and non-RT Linux/Windows targets.

Warning
NOT suitable for hard-RT use: steady_clock has no jitter guarantee. On Linux RT, replace with a clock_gettime(CLOCK_MONOTONIC) implementation; on FreeRTOS, replace with xTaskGetTickCount().

Usage:

ctrl::StdTimer timer;
uint64_t t0 = timer.nowNs();
ctrl.compute(error);
uint64_t dt = timer.elapsedNs(t0);
if (dt > period_ns) std::cerr << "overrun: " << dt << " ns\n";

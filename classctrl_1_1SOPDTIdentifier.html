IMC-PID tuning from a SOPDT model (Rivera 1986 extended for SOPDT).

Uses the equivalent FOPDT approximation tau_eq = tau1 + tau2:

Kp = tau_eq / (K * (lambdaC + theta / 2))
Ti = tau_eq
Td = tau1 * tau2 / (tau1 + tau2) [zero for PI mode]

Rule of thumb: lambdaC = (1..2) * max(tau_eq, theta) for moderate speed.

Parameters
modelIdentified SOPDT model.
lambdaCDesired closed-loop time constant [s]. Larger = more conservative.
TsController sample time [s].
piOnlyIf true, Td is set to zero (PI mode).
Returns
DiscretePIDParams ready for DiscretePID construction.

◆ StackMode

enum class ctrl::StackMode
strong

Orchestration strategy for ControllerStack.

Enumerator
Supervisory 

Only one controller is active per step.

Entries are evaluated in insertion order. The first entry whose activationCondition returns true and whose isHealthy() returns true is selected. An unhealthy controller is skipped with a stderr warning, enabling automatic fallback (e.g., MPC → GPC → PID when the QP consistently fails).

On controller change, bumplessInit() is called on the newly selected entry to prevent an output bump.

If no entry is active, eligible, and healthy, the output holds at the previous value and a warning is emitted. Ensure at least one always-eligible, always-healthy entry (e.g., a PID) to avoid this.

Use for: gain-scheduled switching, mode-based selection, fallback chains.

Additive 

All enabled entries contribute; their outputs are summed.

Use for: inner/outer cascade (fast PID + slow MPC trim), complementary power splitting.

Weighted 

Normalised weighted average of all enabled, gate-passing entries.

u = (Σ wᵢ·uᵢ(e)) / (Σ wᵢ) over active, gate-passing entries only

The denominator is the sum of active and gate-passing weights only. When an entry's activationCondition returns false, its weight is excluded from the denominator, so the remaining controllers automatically fill the full output range. Set all conditions to nullptr for a static blend.

Example with weights [0.7, 0.3]:

  • Both active: u = 0.7·u0 + 0.3·u1
  • Entry 0 gates out: u = u1 (entry 1 gets full authority)

If all entries are inactive, the output holds and a warning is emitted.

Use for: blended controller transitions, fuzzy membership weighting.

◆ c2d()

StateSpace ctrl::c2d ( const StateSpace &  sys_c,
double  Ts,
C2dMethod  method = C2dMethod::ZOH,
double  prewarp_freq = 0.0 
)

Discretise a continuous-time state-space model.

The input StateSpace must have Ts == 0.0 to indicate continuous time.

ZOH (zero-order hold) — uses the Van Loan (1978) matrix-exponential embedding:

M = expm([Ac Bc; 0 0] · Ts) → Ad = M[:n,:n], Bd = M[:n,n:]

Tustin — bilinear transform s = (2/Ts)·(z−1)/(z+1):

Ad = (I − α·Ac)⁻¹·(I + α·Ac), Bd = Ts·(I − α·Ac)⁻¹·Bc, α = Ts/2

TustinPrewarped — bilinear transform with frequency prewarping at prewarp_freq [rad/s], so that the discrete frequency response matches the continuous response exactly at that frequency. Degenerates to standard Tustin when prewarp_freq = 0.

Cd and Dd are unchanged for all methods. A stability warning is printed to stderr if any eigenvalue of Ad lies outside the unit disk.

Equivalent MATLAB: ‘c2d(sys_c, Ts, 'zoh’)/c2d(sys_c, Ts, 'tustin')`

Parameters
sys_cContinuous-time model (Ts must be 0.0).
TsDesired sample period [s].
methodDiscretisation method (default: ZOH).
prewarp_freqPrewarping frequency [rad/s] (only used for TustinPrewarped).
Returns
Equivalent discrete-time StateSpace model.

Automated system-order selection from the singular-value spectrum.

Uses the maximum-consecutive-ratio heuristic: finds the index i* where sv(i*)/sv(i*+1) is largest (sharpest drop) and returns i*+1 as the suggested order. A secondary threshold guard caps the result at the first index where sv(i)/sv(0) falls below threshold.

Use after n4sid() to eliminate the manual elbow-inspection step in adaptive loops (e.g., RLS → n4sid → GPC).

Parameters

thresholdRelative floor; singular values below threshold·sv(0) are treated as noise. Set to 0 to disable the threshold guard.
maxOrderHard cap on the returned order (−1 = no cap).
Returns
Suggested model order ≥ 1.

Koopman / Extended Dynamic Mode Decomposition (EDMD).

Williams, Kevrekidis & Rowley (2015) / Proctor et al. (2016, DMDc). Lifts nonlinear I/O data into a high-dimensional linear space via a dictionary of observable functions ψ(x), then estimates a linear operator K:

z[k] = ψ(x[k], u[k]) (lifting map)
z[k+1] approx = K . z[k] (linear dynamics in lifted space)

The result is projected back onto the original state coordinates to give a ctrl::StateSpace that can be used directly with DiscreteMPC, DiscreteLQR, DiscreteLQG, and DiscreteHinf.

Dictionary options:

  • PolyDeg1 : [1; x; u] (recovers a linear model, equivalent to DMDc)
  • PolyDeg2 : [1; x; u; x^2; xu; u^2] (quadratic lifting)
  • RBF : Gaussian radial-basis functions centred on training data

◆ StackMode

enum class ctrl::StackMode
strong

Orchestration strategy for ControllerStack.

Enumerator
Supervisory 

Only one controller is active per step.

Entries are evaluated in insertion order. The first entry whose activationCondition returns true and whose isHealthy() returns true is selected. An unhealthy controller is skipped with a stderr warning, enabling automatic fallback (e.g., MPC -> GPC -> PID when the QP consistently fails).

On controller change, bumplessInit() is called on the newly selected entry to prevent an output bump.

If no entry is active, eligible, and healthy, the output holds at the previous value and a warning is emitted. Ensure at least one always-eligible, always-healthy entry (e.g., a PID) to avoid this.

Use for: gain-scheduled switching, mode-based selection, fallback chains.

Additive 

All enabled entries contribute; their outputs are summed.

Use for: inner/outer cascade (fast PID + slow MPC trim), complementary power splitting.

Weighted 

Normalised weighted average of all enabled, gate-passing entries.

u = (Sigma w_i.u_i(e)) / (Sigma w_i) over active, gate-passing entries only

The denominator is the sum of active and gate-passing weights only. When an entry's activationCondition returns false, its weight is excluded from the denominator, so the remaining controllers automatically fill the full output range. Set all conditions to nullptr for a static blend.

Example with weights [0.7, 0.3]:

  • Both active: u = 0.7.u0 + 0.3.u1
  • Entry 0 gates out: u = u1 (entry 1 gets full authority)

If all entries are inactive, the output holds and a warning is emitted.

Use for: blended controller transitions, fuzzy membership weighting.

Discretise a continuous-time state-space model.

ZOH (zero-order hold) - uses the Van Loan (1978) matrix-exponential embedding:

M = expm([Ac Bc; 0 0] . Ts) -> Ad = M[:n,:n], Bd = M[:n,n:]

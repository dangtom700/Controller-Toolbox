Detailed Description

Generic anti-windup decorator for any IController.

Thread safety: not thread-safe. All calls must come from the same thread.

◆ setActualOutput()

void ctrl::AntiWindupWrapper::setActualOutput ( double  u_applied)
inline

Feed back the true applied actuator output for external clamping.

Call this after compute() when the actual output applied to the plant differs from the internally clamped value (hardware DAC clipping, external override, etc.). The wrapper re-computes the conditioning correction using (u_applied - u_raw) instead of the internal clamp result.

Must be called before the next compute(); its effect lasts one step.

Parameters
u_appliedActual output applied to the plant this step.

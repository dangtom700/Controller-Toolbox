7// Discrete-time Linear Quadratic Gaussian (LQG) Controller.
8//
9// Combines:
10// - DiscreteLQR - optimal state-feedback gain K (solved offline via DARE)
11// - KalmanFilter - optimal state estimator (handles noisy / partial observations)
12//
13// Separation principle: the LQR and Kalman filter can be designed independently
14// and combined without loss of optimality (Wonham 1968).
15//
16// Scope limitation: the separation principle holds exactly only for linear systems
17// with additive Gaussian noise. For nonlinear plants (e.g., tug-boat dynamics,
18// boiler-turbine), this class linearises the plant model at construction time.
19// Stability and performance guarantees apply only in the neighbourhood of the
20// linearisation point. For larger operating regions consider:
21// - DiscreteLQG with periodic re-linearisation (call the constructor at each
22// operating point and update the gain), or
23// - ExtendedKalmanFilter + DiscreteLQR used as separate objects, allowing the
24// Jacobian to be recomputed at each step inside the EKF.
25//
26// Control law:
27// 1. Kalman predict: x^[k|k-1] from u[k-1]
28// 2. Kalman update: x^[k|k] from y[k]
29// 3. LQR control: u[k] = -K.(x^[k|k] - x_ref)
30//
31// step(y, u_prev, x_ref) performs all three in the correct order.
32//
33// IMPORTANT: compute(y) takes the raw plant output (NOT the error).
34// Use setReference(x_ref) before calling compute(y) for IController compat.
35//
36// Ref: Athans (1971) "Role of Decision Theory in Systems Engineering";
37// MATLAB lqg(), kalman(); Astrom "Introduction to Stochastic Control".

8// Smith Predictor - compensates for pure integer dead-time in discrete plants.
9//
10// Replaces the dead-time delay in the feedback path with a prediction from
11// an internal model, so the inner controller C(z) sees a delay-free loop.
12//
13// Modified error delivered to the inner controller:
14// e_sp[k] = (r[k] - y[k]) + (yhat_model[k] - yhat_model[k-d])
15// = error + (current model output - d-step-delayed model output)
16//
17// Signal-flow equivalent (ref: Smith 1957):
18// Inner loop: C(z) -> P0(z) . z^{-d} (plant with delay)
19// Model: yhat = P0(z) . u (model without delay)
20// Correction: c = yhat - z^{-d}.yhat (delay-induced error cancelled)
21//
22// Requirements: plant model P0 must represent the delay-FREE dynamics.
23//
24// Fractional dead-time support:
25// If the true dead time theta is not a multiple of Ts, pass the optional
26// fracDelayFilter argument (a 1-state StateSpace from padeDelayFilter()).
27// The filter H_frac is connected in series with delayModel so the effective
28// model is P0_eff(z) = H_frac(z) . P0(z), matching e^{-theta_frac * s}
29// to first order without rounding error.
30//
31// Convenience construction via the whole dead time:
32// ctrl::SmithPredictor sp(inner, G0, theta, Ts);
33// This overload splits theta automatically into floor(theta/Ts) integer steps
34// plus a first-order Pade filter for the remainder.
35//
36// Ref: Smith (1957); Astrom & Wittenmark "Computer Controlled Systems" Sec 6.4.

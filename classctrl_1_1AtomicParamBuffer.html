void ctrl::AtomicParamBuffer< Params >::publish ( const Params &  p)
inline

Publish a new parameter set (background thread).

Writes p to the inactive buffer slot, then atomically promotes it by updating active_. The sequence counter brackets the write so readers can detect and retry if they overlap the update.

Parameters
pNew parameter values to publish.

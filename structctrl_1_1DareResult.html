Detailed Description

Result returned by Discrete Algebraic Riccati Equation (DARE) solvers.

Shared between DiscreteLQR (value-iteration doubling) and DiscreteHinf (symplectic pencil Schur method). Using a common type allows diagnostics code to handle both without knowing which solver produced the result.

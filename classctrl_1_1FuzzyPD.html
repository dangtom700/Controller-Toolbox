Detailed Description

5-term PD fuzzy controller implementing IController.

Inputs: error e[k] and error-rate de[k] = (e[k] - e[k-1]) / Ts. Output: control effort u[k].

Uses a standard 5-term partition (NL, NS, ZE, PS, PL) with triangular and shoulder membership functions and a 25-rule canonical diagonal Mamdani table.

Scaling:

e_norm = e / e_scale \in [-1, 1]
de_norm = de / de_scale \in [-1, 1]
u = u_norm * u_scale

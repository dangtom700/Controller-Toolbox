9// ControllerStack - runs multiple discrete controllers in supervisory or complementary modes.
10//
11// StackMode::Supervisory
12// Only one controller is active per step. Entries are evaluated in insertion order;
13// the first whose activationCondition returns true AND whose isHealthy() returns true
14// is selected. If no condition is registered for an entry, that entry is always eligible.
15// isHealthy() == false causes the entry to be skipped with a stderr warning, enabling
16// automatic fallback: e.g., MPC (QP diverged) -> GPC -> PID without manual intervention.
17// Edge case: if no entry is active, eligible, and healthy, the output holds at the
18// previous value (bumpless hold) and a warning is emitted on stderr. Ensure at least
19// one always-eligible, always-healthy fallback entry (e.g., a PID) to avoid this.
20// Use for: gain-scheduled switching, mode-based selection, fallback chains.
21//
22// Supervisory mode pseudocode:
23// for each entry e in stack (insertion order):
24// if e.active AND (e.condition == nullptr OR e.condition(error, lastOutput))
25// AND e.controller->isHealthy():
26// if e.controller != last_active:
27// e.controller->bumplessInit(lastOutput, error) // bump-free handover
28// last_active = e.controller
29// return e.controller->compute(error)
30// // no eligible entry:
31// std::cerr << "ControllerStack::Supervisory: no eligible entry. Holding last output."
32// return lastOutput // bumpless hold
33//
34// StackMode::Additive
35// All enabled entries contribute; their outputs are summed.
36// Use for: inner/outer cascade (fast PID + slow MPC trim), complementary power splitting.
37//
38// StackMode::Weighted
39// Normalised weighted average of all enabled, gate-passing entries:
40// u = (Sigma w_i . u_i(e)) / (Sigma w_i) over active, gate-passing entries only.
41// Note: the denominator is the sum of *active and gate-passing* weights, not all
42// stated weights. If an entry's activationCondition returns false, its weight is
43// excluded from the denominator, so the remaining controllers automatically "fill" the
44// full output range. Set all activationConditions to nullptr for a static blend.
45// Edge case: if all entries are inactive or gate out, the output holds at the
46// previous value (bumpless hold) and a warning is emitted on stderr.
47//
48// Weighted mode pseudocode:
49// total_w = 0; out = 0;
50// for each entry e in stack:
51// if e.active AND (e.condition == nullptr OR e.condition(error, lastOutput)):
52// out += e.weight * e.controller->compute(error)
53// total_w += e.weight
54// if total_w > 1e-12:
55// return out / total_w
56// // all entries inactive or gated out:
57// std::cerr << "ControllerStack::Weighted: no active entry. Holding last output."
58// return lastOutput // bumpless hold
59//
60// Example - two controllers with weights [0.7, 0.3]:
61// Both active: u = (0.7*u0 + 0.3*u1) / (0.7 + 0.3) = 0.7*u0 + 0.3*u1
62// Entry 0 gates out: u = (0.3*u1) / (0.3) = u1 (entry 1 gets full authority)
63// This means "weight" is a relative preference, not a fixed gain.
64//
65// Use for: blended controller transitions, fuzzy membership weighting.
66//
67// Ref: Astrom "Control System Design" Ch 9 (Gain Scheduling);
68// MATLAB supervisory control patterns.

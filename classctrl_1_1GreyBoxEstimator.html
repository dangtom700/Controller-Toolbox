Detailed Description

Grey-box nonlinear parameter estimator via Levenberg-Marquardt (E1).

Identifies unknown physical parameters p in a continuous-time ODE: x_dot = f(x, u, p), y = h(x, p)

Given initial state x0, input sequence U (n_u x N), and measurements Y (n_y x N), minimises sum_{k=0}^{N-1} ||y_k - h(x_k(p), p)||^2 w.r.t. p via Levenberg-Marquardt with optional per-parameter bounds.

Integration uses RK4 (rk4_steps substeps per Ts). Parameter Jacobian is computed by central finite differences. Bounds are enforced by projection after each LM step.

Typical usage
// Spring-mass-damper: xdot = [x1, -k/m*x0 - c/m*x1 + u/m]
ctrl::GreyBoxEstimator::OdeFn f = [](auto& x, auto& u, auto& p) {
Eigen::VectorXd xd(2);
xd(0) = x(1);
xd(1) = -p(0)/p(2)*x(0) - p(1)/p(2)*x(1) + u(0)/p(2);
return xd;
};
ctrl::GreyBoxEstimator::MeasFn h = [](auto& x, auto& p) {
return x.head(1); // observe position
};
ctrl::GreyBoxEstimator::Params par;
par.p0 = Eigen::Vector3d(5.0, 0.5, 1.0); // k, c, m initial guess
par.lower = Eigen::Vector3d(0.1, 0.01, 0.1);
par.upper = Eigen::Vector3d(20.0, 5.0, 5.0);
par.Ts = 0.01;
ctrl::GreyBoxEstimator est(f, h, par);
auto res = est.fit(x0, U, Y);

6// Discrete-time Generalised Predictive Controller (GPC).
7//
8// Extends DiscreteMPC with two features aimed at practical deployment:
9//
10// 1. Velocity-form (CARIMA) model - offset-free tracking without a separate
11// integral state. The augmented state xa = [Deltax; y] is propagated with
12// incremental inputs DeltaU, giving a built-in integrating disturbance model.
13//
14// Augmented state-space (n_a = n + p):
15// xa[k+1] = Aa.xa[k] + Ba.Deltau[k] Aa = [A, 0; C.A, I]
16// y[k] = Ca.xa[k] Ba = [B; C.B], Ca = [0, I]
17//
18// 2. Reference trajectory - setpoint is approached along a first-order filter
19// y*[k+j] = alpha^j.y[k] + (1-alpha^j).r[k], alpha \in [0,1)
20// instead of a step. Reduces overshoot without tuning derivative weights.
21// alpha = 0: step reference (same as DiscreteMPC). alpha -> 1: very soft approach.
22//
23// Prediction (condensed form, same QP structure as DiscreteMPC):
24// Y_pred = Fa.xa[k] + Ga.DeltaU
25// DeltaU* = -(Ga'.Q.Ga + R)^-1 . Ga'.Q.(Fa.xa - R_traj)
26//
27// Output Constraints Note:
28// GPC natively enforces bounds on control effort (uMin, uMax) and rate (duMin, duMax).
29// It does NOT currently support hard constraints on the output trajectory (y_min, y_max).
30// In predictive control, output constraints often cause infeasibility if disturbances
31// push the state outside the feasible region. If you require hard output constraints,
32// use DiscreteMPC with a suitable slack-variable formulation instead.
33//
34// The plant model can be hot-swapped via setPlant() for adaptive GPC
35// (pair with RecursiveLeastSquares::toStateSpace() for a self-tuning loop).
36//
37// Ref: Clarke et al. "Generalised Predictive Control" Automatica (1987);
38// Mohtadi & Clarke "GPC: further results" IEE (1987);
39// Maciejowski "Predictive Control with Constraints" (2002) Ch.3.

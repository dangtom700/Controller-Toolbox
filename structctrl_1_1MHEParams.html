◆ C_ineq

Eigen::MatrixXd ctrl::MHEParams::C_ineq

General linear inequality constraints on the arrival state x_0 (E4).

Enforces C_ineq * x_0 <= d_ineq after the FISTA solve via Hildreth's cyclic half-space projections. Useful for:

  • Simplex constraints: mole fractions sum to 1, all non-negative.
  • Coupled bounds: e.g. x_1 + x_2 <= 1.
  • Any polytope expressible as a set of linear inequalities.

Set C_ineq (m_c x n) and d_ineq (m_c) together; both must be non-empty for the constraint to be active. Box constraints xMin / xMax are re-applied after the polytope projection so both are simultaneously satisfied.

Parameters
C_ineqConstraint matrix (m_c x n), empty = no polytopic constraint.
d_ineqConstraint RHS (m_c x 1).
ineq_proj_itersHildreth iterations (default 20, usually sufficient). Polytope constraint LHS (m_c x n), empty = off.

◆ xMin

Eigen::VectorXd ctrl::MHEParams::xMin

Per-element lower bound on the arrival state x_0 (size n, or empty = unconstrained).

x_0 is the oldest state in the estimation window and is the first n elements of the QP decision variable. Constraining it prevents physically impossible values (e.g. negative concentrations) from entering the estimate.

Note
Only x_0 is directly box-constrained. States x_1..x_N are determined by the dynamics x_{i+1} = A*x_i + B*u_i + w_i; to bound them, also tighten wMin/wMax so that the propagation cannot drift outside the intended region. Lower box bound on x_0 (size n), empty = no constraint.
